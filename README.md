# HireLens

A multi-agent resume-to-job fit checker (Agentic AI CA3).

Upload a resume and a job description or link; a team of AI agents scores the fit section by section, checks each other's work, and suggests improvements.

**Team:** Arya Sanjay Bhirud · Aryan Choudhary · Arun Tati

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest -q
```

Work in progress: foundations first, then the agents, then the app.
